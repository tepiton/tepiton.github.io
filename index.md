- [eleventy-chapbook](https://github.com/tepiton/eleventy-chapbook)
  - [sample](https://tepiton.com/eleventy-chapbook/)
  - An Eleventy v3 starter for chaptered literary sites. Designed for serialized fiction, novellas, and other long-form prose.

- [eleventy-folio](https://github.com/tepiton/eleventy-folio)
  - [sample](https://tepiton.com/eleventy-folio/)
  - An Eleventy v3 starter for chaptered literary sites. Polished defaults, extra features.

- [eleventy-pamphlet](https://github.com/tepiton/eleventy-pamphlet)
  - [sample](https://tepiton.com/eleventy-pamphlet/)
  - An Eleventy v3 starter for short literary works: novellas, single-volume fiction, pamphlets. Minimal structure with two layouts.

- [eleventy-prose-blog](https://github.com/tepiton/eleventy-prose-blog)
  - [sample](https://tepiton.com/eleventy-prose-blog/)
  - An Eleventy v3 starter for personal prose blogs. Designed for writers who want a polished reading experience: footnote popovers, light/dark theming, RSS feeds, and image optimization.

- [eleventy-tech-blog](https://github.com/tepiton/eleventy-tech-blog)
  - [sample](https://tepiton.com/eleventy-tech-blog/)
  - An Eleventy v3 starter for developer blogs. Designed for technical writing: Mermaid diagrams, syntax highlighting, light/dark theming, RSS feeds, and image optimization.

- [eleventy-product](https://github.com/tepiton/eleventy-product)
  - [sample](https://tepiton.com/eleventy-product/)
  - A product landing page template built with Eleventy v3: a section-composed homepage where every band of the page is a Markdown file.

- [eleventy-service](https://github.com/tepiton/eleventy-service)
  - [sample](https://tepiton.com/eleventy-service/)
  - A service business landing page template built with Eleventy v3: a section-composed homepage where every band of the page is a Markdown file.

- [pandoc-simple](https://github.com/tepiton/pandoc-simple)
  - [sample](https://tepiton.com/pandoc-simple/)
  - A pandoc-based single-page Markdown site with no SSG toolchain.

- [mimeo](https://github.com/tepiton/mimeo)
  - [sample](https://mimeo.lol/)
  - Placeholder template that shows the name of the site

- [laptopistan](https://github.com/tepiton/laptopistan)
  - [sample](https://tepiton.com/laptopistan/)
  - Placeholder template that displays a picture from picsum.photos
